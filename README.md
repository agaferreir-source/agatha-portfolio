# Agatha Pinheiro | Portfólio

Portfólio profissional de Agatha Pinheiro para desenvolvimento web, sistemas,
automações e soluções digitais personalizadas.

## Tecnologias

- Next.js 14 com App Router
- TypeScript
- React
- CSS responsivo e `lucide-react`

## Executar

```bash
npm install
npm run dev
```

Abra `http://localhost:3000` no navegador. Para produção:

```bash
npm run build
npm run start
```

## Conteúdo e contatos

- Contatos, links e identidade ficam em `lib/data.ts`.
- Projetos, feedbacks e FAQ são dados reutilizáveis no mesmo arquivo.
- O formulário valida os campos e abre o WhatsApp; ele não envia e-mail nem armazena dados.
- O e-mail alternativo, WhatsApp e Instagram estão configurados em `siteConfig`.

## Imagens

Adicione os arquivos oficiais em `public/images/brand/`, especialmente:

- `hero-character.png`
- `favicon.png`
- `og-image.png` (opcional)

As imagens reais dos projetos podem ser organizadas em `public/images/projects/`.
Enquanto elas não existem, a interface exibe placeholders identificados, sem
apresentá-los como screenshots reais.
